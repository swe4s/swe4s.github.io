Software Engineering for Scientists is a course for upper-level undergraduates and graduate students in the sciences who want to enhance their research by developing custom software. This class will build off basic programming skills to enable the development of robust and reliable software for reproducible science. These skills will sample core elements from both software engineering (e.g., version control, testing and continuous integration, debugging, benchmarking, documentation, distribution) and software design (e.g., algorithm analysis, sorting and searching, file input and output, text parsing, basic data structures), and will be organized around the ingestion and processing of data for many different scientific domains.

## Learning objectives

### 1. Knowledge & Understanding

By the end of this course, students will be able to:

- Explain the fundamental principles of software engineering and their application to scientific research.
- Understand core concepts of software design, including algorithm analysis, sorting and searching, file input and output, text parsing, and basic data structures.
- Recognize the importance of reproducibility in scientific computing and the role of software in achieving it.

### 2. Software Development & Engineering Practices

Students will gain practical experience in:

- Using version control (e.g., Git) to manage and track software development collaboratively.
- Implementing testing and continuous integration to ensure software reliability and correctness.
- Applying debugging techniques to identify and resolve software issues efficiently.
- Benchmarking software performance to optimize computational efficiency.
- Writing clear, structured, and maintainable code with comprehensive documentation.
- Packaging and distributing scientific software to ensure accessibility and usability by other researchers.

### 3. Scientific Computing & Data Processing

This course emphasizes working with data across various scientific domains, enabling students to:

- Develop software that ingests and processes scientific data efficiently and accurately.
- Implement file handling techniques for structured and unstructured data storage.
- Parse and analyze text-based scientific data using programmatic approaches.
- Choose and implement appropriate data structures for managing and processing scientific data effectively.

### 4. Reproducibility & Best Practices in Research Computing

Students will develop a professional approach to computational research, including:

- Writing code that adheres to best practices in scientific computing.
- Ensuring computational experiments are reproducible through proper software management and documentation.
- Collaborating effectively with researchers from different disciplines using software engineering tools and methodologies.

These objectives will prepare students to build robust, reliable, and reproducible software that enhances scientific research across various fields.

## Assignments

All assignments and grading will be through GitHub. We will post the link to the assignment — go to the link, accept the assignment, and clone the repository. All assignments must adhere to Python best practices and use the proper GitHub workflow. Unless directed otherwise, we will only consider the `v1.0` release and use the date of that release as the submit time.

- **Late assignments will not be considered.**
- **Assignments without the correct release will not be considered.**
- You may work together on assignments, but original contributions are expected from every student.
- In most cases, assignments will be due at 5 PM one week after they are posted.

See the [Assignments]({{ '/assignments/' | relative_url }}) page for the current list and due dates.

## Project

All graduate students must propose and submit a project. Each project will have between two and three team members. A team may not have more than two graduate students. Undergraduates are encouraged but not required to either join a team or develop their own project, and a team of three must have at least one undergraduate.

Projects can address any scientific question and must incorporate all of the software engineering and software design topics covered in class. The question does not need to be novel, but all contributions must be original. Teams are encouraged, but not required, to meet with the instructor about their topic.

A short in-class project pitch will focus on the scientific question, and a longer final presentation will focus on the resulting software product and any results. Each team will perform and present a code review of another team's code.
